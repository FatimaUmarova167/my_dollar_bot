# Телеграм-Бот курса валют доллар/евро
Название:
my_dollar_bot

## Описание:
Бот который показывает курс доллара/евро при команде /dollar
**Юзернейм бота:** @KursoMan_valuta_USD_bot

## Инструкция: 
установите зависимости 
pip install -r requirements.txt

Запуск:
python dollar_bot.py

## ожидание:
бот должен ответить на команду старт в течении 1-2 секунд,
в терминале должно появиться лог-сообщение 
"🚀 Бот успешно запущен и готов к работе!
📊 Отправьте команду /dollar в Telegram для проверки
"
